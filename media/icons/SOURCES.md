# 아이콘·이미지 출처

- `pdf.svg`: 이 공개 패키지를 위해 작성한 문서 아이콘.
- `globe.svg`, `youtube.svg`: README의 웹 포트폴리오·유튜브 링크를 식별하기 위해 작성한 SVG 아이콘. YouTube 브랜드의 권리는 해당 권리자에게 있습니다.
- `steam.png`: 사용자가 제공한 PixelChroma 포트폴리오 PDF 1페이지의 Steam 로고를 추출. Steam 및 Steam 로고는 Valve의 상표이며, Steam 스토어 링크 식별 용도로 사용합니다. 별도의 재사용 허락을 선언하지 않습니다.
- `../project-highlights.png`, `../paint-mask.png`, `../emboss-comparison.png`, `../font-tool.png`: 제공된 포트폴리오 PDF의 1·2·5·10페이지에서 추출. 게임 아트·화면·자료의 권리는 각 권리자에게 있습니다.
- `../paint-mask-composition.png`, `../paint-input-sync.png`: 캔바 포트폴리오 12·13페이지와 동일한 공개 패키지 PDF 2·3페이지에서 상단 도식만 추출. 각각 공통 페인트 마스크 합성과 입력 전송 방식을 설명하며, 도식 내용은 수정하지 않았습니다.
- `../runner-camouflage.gif`, `../seeker-search.gif`: 사용자가 제공한 PixelChroma 원본 플레이 영상에서 러너의 색칠 위장과 시커의 물총 수색 장면을 각각 8초씩 추출. 게임 아트·화면의 권리는 각 권리자에게 있습니다.
